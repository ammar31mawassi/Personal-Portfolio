01 flagship AI software

AI Job Tracker

A privacy-safe full-stack product that imports job-related emails, normalizes statuses, explains rejection patterns as hypotheses, and turns career progress into next actions.

Open details
  • Next.js
  • FastAPI
  • SQLite / SQLModel
  • Gmail readonly design
  • OpenAI structured extraction
  • Pytest

This project is built around the strongest public story for AI software roles: useful automation that respects privacy. It uses fake demo fixtures for public proof, local-only credentials for real integrations, and explicit boundaries around Gmail permissions and AI-generated hypotheses.

  • Normalizes job email evidence into companies, roles, status, source, dates, and next actions.
  • Merges duplicate evidence and distinguishes rejection, interview, action-needed, and lead messages.
  • Documents privacy choices so the project is recruiter-readable without exposing real personal data.

02 interactive Java game

Code Escape

A JavaFX 2D educational escape-room game where players collect programming tokens and assemble valid Java statements to unlock rooms and progress through levels.

Open details
  • Java
  • JavaFX
  • Game state
  • Code validation
  • JUnit 5
  • Pixel UI

Code Escape turns Java fundamentals into a playable puzzle loop: move through a room, collect tokens like int, x, =, 5, and ;, then validate the assembled statement to unlock the door.

  • Implements player movement, collectible tokens, inventory, levels, doors, terminal interactions, and achievement feedback.
  • Uses validators for concepts such as variables, if-statements, classes, and Java syntax rules.
  • Backed by tests for game state, level management, progress behavior, and validation logic.
